# Rendered previews

These images were rendered from this project's QML at 1920×1080 in a headless
Wayland session. The five panel previews use sample desktop state. The native
notification and control-center captures use real Quickshell protocol services
with test notifications and mock media/tray applications. None were captured
from the target Lenovo/Fedora installation. Open `scripts/start.sh --preview`
in a running Wayland session for an interactive preview without desktop mutations.
